# AWH Architects Website

A modern, high-performance web platform for **AWH Architects** — a mission-driven architectural design and planning firm specializing in community-centered spaces, multifamily housing, commercial, historic preservation, and passive house sustainability.

Designed and developed based on the Miro concept architecture and structured site specifications.

---

## 🌟 Key Features & Site Architecture

### 1. Home (`/`)
- **Miro Concept Layout**: Architectural hero showcase with twilight illumination, firm manifesto (*"Where place meets purpose"*), and dual CTA pathways.
- **Expertise Section**: Slate-blue band featuring *Architecture*, *Historic Consulting*, and *Planning & Pre-Development*.
- **Studio Collective Preview**: Multidisciplinary team feature linking directly to leadership and credentials.
- **Markets Grid**: Interactive previews for all 6 core sector areas with hover underlines.
- **Testimonial Banner**: Full-width panoramic prairie pavilion featuring verified client feedback.
- **News & Insights**: Resources and publications preview.
- **Architectural Footer**: Comprehensive navigation, licensing credentials (AIA, LEED AP, CPHC®, NCARB), and office coordinates.

### 2. Markets (`/markets`)
- Comprehensive overview and detail views for **all 8 sectors**:
  - Community & Civic
  - Nonprofits & Mission-Driven
  - Multi-Family Housing
  - Commercial & Mixed-Use
  - Interiors & Workplace
  - Custom Residential
  - Adaptive Reuse & Revitalization
  - Historic Preservation
- Audience profiles, tailored deliverables, client testimonials, and connected projects.

### 3. Services (`/services`)
- 5 core practice disciplines:
  - **Architecture**
  - **Planning & Pre-Development**
  - **Cannabis Facility Design**
  - **Historic Consulting**
  - **Passive House Consulting**
- Detailed methodology, standard deliverables, and direct RFP/consultation pathways.

### 4. Projects & Case Studies (`/projects`)
- Filterable project index with live filtering by **Market**, **Service Discipline**, and **Keyword Search**.
- Standardized **3-Pillar Case Study Format**:
  - 🔴 **The Challenge**
  - 🔵 **AWH's Role**
  - 🟢 **The Outcome & Measurable Impact**
- High-resolution gallery carousel, project specifications, and sustainability benchmarks.

### 5. Resources Hub (`/resources`)
- **Guides**: Downloadable/readable roadmaps (Historic Tax Credits, Passive House Economics, Cannabis Cultivation Facility Playbook).
- **Articles**: Architectural perspectives and building science publications.
- **FAQs**: Expandable client questions regarding fees, zoning, municipal approvals, and tax credits.

### 6. Studio (`/studio`)
- Firm philosophy, 4 core values, team leadership directory with bios and credentials, licensing certifications, and design & preservation awards.

### 7. Interactive Consultation Modal
- Direct project inquiry form pre-populated with client market and service selections.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite 8](https://vite.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: Space Grotesk & Plus Jakarta Sans via Google Fonts

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/meedish-LLC/awh.git

# Navigate to project folder
cd awh

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
